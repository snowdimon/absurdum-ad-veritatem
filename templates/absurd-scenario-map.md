# Карта абсурдных сценариев

> **Назначение:** выявление и документирование потенциально опасных гротескных
> пределов ключевых правил системы. Заполняется на этапе проектирования,
> уточняется при прототипировании и обновляется при обнаружении инцидентов.

---

## Структура записи

| Поле | Описание |
| :--- | :--- |
| **ID** | Уникальный идентификатор сценария (например, `AS-001`) |
| **Ключевое правило** | Формулировка правила системы, которое анализируется |
| **Домен** | Область системы, к которой относится правило (например, `Идентификация`, `Доступ`, `Страхование`) |
| **Гротескный сценарий** | Описание ситуации, в которой правило доведено до абсолюта — буквального, карикатурного или злонамеренного исполнения |
| **Вероятность** | Оценка вероятности реализации сценария: `Низкая`, `Средняя`, `Высокая`, `Неизбежная` |
| **Ущерб** | Оценка потенциальных последствий: `Низкий`, `Средний`, `Высокий`, `Критический` |
| **Индикаторы приближения** | Признаки, по которым можно заметить, что система движется к данному сценарию |
| **Контрмера** | Архитектурное, процедурное или техническое решение, предотвращающее сценарий или смягчающее его последствия |
| **Статус** | `Открыт`, `Проработан`, `Закрыт`, `Мониторинг` |

## Пример заполнения (из проекта Duranki)

| Поле | Значение |
| :--- | :--- |
| **ID** | AS-001 |
| **Ключевое правило** | EVA (выход в открытый космос) даёт «статус риска» в стеке опыта |
| **Домен** | Страхование / Управление рисками |
| **Гротескный сценарий** | Страховая компания начинает использовать «статус риска» как понижающий коэффициент. Капитаны кораблей, чтобы минимизировать страховые взносы, принуждают экипаж к необоснованным выходам в открытый космос для «набивки стека». Стек из зеркала опыта превращается в инструмент принуждения и неравенства |
| **Вероятность** | Средняя |
| **Ущерб** | Высокий (дискредитация системы, физический риск для экипажа, неравенство) |
| **Индикаторы приближения** | Появление страховых продуктов, привязанных к стеку; жалобы экипажей на необоснованные EVA; статистические аномалии по частоте выходов |
| **Контрмера** | Архитектурно разделить «сырой опыт» и «юридические привилегии»; запрет на автоматическое использование стека для расчёта страховых коэффициентов; аудит назначаемых EVA |
| **Статус** | Проработан |
